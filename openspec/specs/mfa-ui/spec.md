## Requirements

### Requirement: 账号列表展示动态码
列表必须展示每个账号的名称、添加时间、当前 6 位口令和剩余时间进度条，口令必须随周期自动刷新。

#### Scenario: 进度条随剩余时间收缩
- **当** 周期剩余时间减少
- **则** 进度条宽度必须等比收缩，并在剩余 5 秒内变为警示色

#### Scenario: 口令自动刷新
- **当** 当前周期结束
- **则** 无需任何用户操作，列表中所有口令必须同时更新

#### Scenario: 点击复制
- **当** 用户点击某个账号卡片
- **则** 必须把该口令复制到剪贴板并给出提示

#### Scenario: 空列表引导
- **当** 尚未添加任何账号
- **则** 必须展示空状态引导用户添加，而不是一片空白

### Requirement: 搜索账号
列表必须支持按账号名称过滤。

#### Scenario: 按关键词过滤
- **当** 在搜索框输入关键词
- **则** 必须只保留名称或发行方包含该关键词的账号，忽略大小写

### Requirement: 扫码添加
系统必须支持相机扫描 otpauth 二维码添加账号。

#### Scenario: 扫描有效二维码
- **当** 相机识别到合法的 `otpauth://totp/` 二维码
- **则** 必须停止扫描并跳转到确认页，预填发行方与账号名

#### Scenario: 扫描无效二维码
- **当** 识别到的二维码不是合法 otpauth URI
- **则** 必须提示无法识别并继续扫描，不得退出扫码页

#### Scenario: 相机权限被拒
- **当** 用户拒绝相机权限
- **则** 必须提示前往设置开启，并提供改用手动添加的入口

### Requirement: 手动添加
系统必须支持手工填写账号名与 Base32 密钥添加账号。

#### Scenario: 必填校验
- **当** 账号名或密钥为空
- **则** 「确定」按钮必须处于禁用状态

#### Scenario: 密钥非法
- **当** 输入的密钥不是合法 Base32
- **则** 必须在提交时提示密钥格式错误，不得添加账号

### Requirement: 备份与导入入口
主页必须提供备份与导入备份的入口，导出经系统「文件」保存，导入从「文件」选取。

#### Scenario: 导出到文件
- **当** 用户选择「备份 MFA」并设置密码
- **则** 必须弹出系统文件保存面板，由用户选定保存位置

#### Scenario: 从文件导入
- **当** 用户选择「导入备份」
- **则** 必须弹出系统文件选择面板，且只允许选取 `.smfa` 文件
