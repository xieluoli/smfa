## ADDED Requirements

### Requirement: 账号本机加密存储
系统必须把账号密钥存入 iOS Keychain，且仅在设备解锁后可读；App 卸载重装后不得残留。

#### Scenario: 冷启动后账号仍在
- **当** 添加账号后杀掉 App 并重新启动
- **则** 列表必须仍显示该账号且能生成正确口令

#### Scenario: 设备锁定时不可读
- **当** Keychain 项被写入
- **则** 其可访问性必须为 `WhenUnlockedThisDeviceOnly`，不参与 iCloud 钥匙串同步

### Requirement: 账号增删改
系统必须支持添加、重命名、删除账号，删除必须二次确认。

#### Scenario: 添加账号记录时间
- **当** 新增一个账号
- **则** 必须记录添加时间并在列表中展示

#### Scenario: 删除需确认
- **当** 用户点击删除
- **则** 必须弹出确认框，确认后才从存储中移除

### Requirement: 账号去重
系统必须以「发行方 + 账号名 + 密钥」作为唯一标识判定重复。

#### Scenario: 重复添加同一账号
- **当** 添加的账号与已有账号三项完全相同
- **则** 必须提示已存在，且不产生第二条记录
